🏠 Airbnb Assistant — Landing Page

A modern, fully responsive SaaS landing page for an Airbnb / Short-Term Rental (STR) management assistant platform. Built with Next.js 16, Tailwind CSS v4.2, and react-fast-marquee.

🛠 Tech Stack
<li>Next.js 16</li>
<li>Tailwind CSS 4.2</li>
<li>TypeScript</li>
<li>react-fast-marquee</li>
<li>lucide-react</li>


<h3># 1. Clone the repository</h3>
git clone https://github.com/your-username/airbnb-assistant-landing.git
cd airbnb-assistant-landing

<h3># 2. Install dependencie</h3>
npm install

<h3># 3. Install the required package</h3>
npm install react-fast-marquee

<h3># 4. Start the development server</h3>
npm run dev
